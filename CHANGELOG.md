# Changelog

## Version 2.0.0

- Added YAML-driven configuration support and aligned generated configuration files with CLI configuration descriptions.
- Added CIF reading and analysis workflows for batch structural analysis.
- Introduced points-first geometry analysis for distances, angles, torsions, and plane measurements, while retaining compatibility with existing geometry configuration keys.
- Expanded variable-position, position-analysis, and temperature-analysis workflows around the shared geometry and CIF-analysis functionality.
- Consolidated geometry-set configuration and output handling across the updated analysis pipelines.
